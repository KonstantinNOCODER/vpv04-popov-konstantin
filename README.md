# Домашнее задание: Git и GitHub



## 1. Что это

Учебный Python-проект для освоения Git и GitHub. Программа выводит два сообщения в консоль.



## 2. Как запустить

1. Установить Python 3.

2. Открыть терминал в папке проекта.

3. Выполнить команду `python main.py`.



## 3. Как проверить, что работает

После запуска программа должна вывести:



```text

Hello world

Git tracks my changes

```



## 4. Что я сделал в этом уроке

- Создал локальный Git-репозиторий.

- Добавил Python-файл и изменил его.

- Создал два коммита.

- Научился использовать git status, git diff и git log.



## 5. Что было сложным / что понял

Я разобрался, чем обычное сохранение файла отличается от коммита. Теперь понимаю, как Git отслеживает изменения и сохраняет историю проекта. Команда git add подготавливает изменения, а git commit фиксирует их в истории.
